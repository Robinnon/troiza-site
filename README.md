# troiza-site

Страница студии Troiza: https://troiza.cubyplay.com

Одна статическая страница `index.html` на английском: первый экран с фоном из наших игр, карточки игр с оценками площадок, подвал. Хостинг — GitHub Pages репозитория Robinnon/troiza-site (ветка main, корень), домен задан файлом `CNAME`; запись DNS `troiza.cubyplay.com CNAME robinnon.github.io` в Porkbun. `googlea93a35a27c40f3e9.html` — подтверждение сайта в Google Search Console.

- `img/hero-wide.webp` (2560) и `img/hero-wide-1600.webp` — фон первого экрана на ПК, `img/hero-tall.webp` — на телефоне (экран уже 4:5); `img/hero-wide.jpg` — картинка для превью ссылок (og:image).
- `img/i-cloned-myself.webp`, `img/egg-heist-tower.webp` — картинки карточек игр.
- `img/logo.webp` — логотип в шапке и подвале; `img/icon-64.png` и `img/apple-touch-icon.png` — знак логотипа для вкладки и иконки на телефоне.
- `fonts/` — Lilita One (заголовки, шрифт наших игр) и Nunito, только латиница, лицензия OFL в `fonts/OFL.txt`.

Числа на странице — только публичные, со страниц игр на площадках.

Обновить: поправить `index.html`, закоммитить и запушить в main — Pages выкладывает сам за минуту-две.
