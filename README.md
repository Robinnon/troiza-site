# troiza-site

Страница студии Troiza для Google Play Console: https://troiza.cubyplay.com

Один статический `index.html` и обложки игр в `img/`. Хостинг — GitHub Pages репозитория Robinnon/troiza-site (ветка main, корень), домен задан файлом `CNAME`; запись DNS `troiza.cubyplay.com CNAME robinnon.github.io` в Porkbun.

Обновить: поправить `index.html`, закоммитить и запушить в main — Pages выкладывает сам за минуту-две.
